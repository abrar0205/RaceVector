# RaceVector visual prototype

This is a dependency-free, responsive **visual spike**, not the final production interface. Serve this directory with `python -m http.server 8000 --directory web` from the repo root and open http://localhost:8000.

The **Load real session** action fetches OpenF1 `/sessions`, `/drivers`, `/laps`, `/car_data` and `/location`. It chooses the two drivers with the fastest valid recorded lap and draws their measured telemetry. A same-origin pre-export generated by `pipeline/ingest.py` is preferred when available. This first visualization uses **time-normalized** lap progress, not official sector or distance-based delta. Approximate position telemetry cannot support racing-line precision claims.

There are **no embedded fabricated telemetry samples**, and the neural model panel explicitly says no checkpoint is present. API access may be rate-limited or limited by CORS, so export a real session and serve its JSON when needed.

Future UI work: Three.js + React Three Fiber GPU-enhanced track ribbon based on the same real sampled coordinates; motion-aware detail transitions; input attribution and hidden activations produced by evaluated model, not random animation. Do not add invented predictions to fill UI states.
